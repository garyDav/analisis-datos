## Instalación de MySQL Workbench

## Importar CSV

* Creamos un archivo SQL File

* Añadimos el y ejecutamos el siguiente script:

```sql
CREATE DATABASE Importar;
USE Importar;
```

* Click derecho (⋮) en la base de datos -> Table Data Import Wizard -> Buscamos el archivo CSV `bank.csv`, reconoce el tipo de campo -> todo next.

* Actualizamos `SCHEMAS` -> Visualizamos la tabla `bank`, sus columnas.

* (⋮) en `bank` -> `Select Rows - Limit 1000`, observamos que estan todos los registros.
